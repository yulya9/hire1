# Hire: вакансия за четыре ответа

Тестовое задание UX/UI Frontend для «Лаборатории ПИИ»: голосовое создание вакансии. Человек отвечает на четыре вопроса вслух или текстом, система сама собирает из ответов текст вакансии с разделами. Круг в центре экрана заполняется по мере ответов.

**Открыть:** <https://yulya9.github.io/hire1/> (голос работает в Chrome и Edge, в остальных браузерах можно печатать).

## Что внутри

| Папка или файл | Что это |
|---|---|
| `прототип/index.html` | Рабочий прототип, один файл, без сборки и библиотек. Остальные файлы описывают его |
| `документы/SPEC.md` | Спецификация: правила, тексты, критерии приёмки. Источник правды |
| `документы/STATES.md` | Матрица состояний и пограничные случаи |
| `документы/HANDOFF.md` | Передача в вёрстку: цвета, размеры, движение, адаптив |
| `документы/AGENTS.md` | Как агенту работать с этим кодом |
| `документы/README.md` | Что сделано, что не вошло, как проверить |
| `документы/PROCESS.md` | Последовательность работ, доля ИИ (около 90%), методологии, использованные спецификации и промпты, что отбраковано |
| `документы/ПРЕЗЕНТАЦИЯ.md` | Описание фичи для пользователя |

## Запуск локально

Страница статическая. Из папки проекта:

```bash
python3 -m http.server 8765
```

Открыть `http://localhost:8765/прототип/index.html`. Микрофон работает на `localhost` и по `https`.

## Сборка через нейросеть (необязательно, для разработчиков)

Сейчас вакансию собирает обычный шаблон: чистит «ну» и «короче» и раскладывает ответы по разделам, ничего не выдумывая. Это работает сразу, ничего вводить не нужно.

Если нужно, чтобы текст писала нейросеть Claude, разработчик может подключить её: открыть `прототип/index.html#settings` (в меню этой страницы нет) и вставить свой «ключ API». Ключ API это личный пароль доступа к Claude, его выдаёт компания Anthropic при регистрации в своём кабинете. Он запоминается только в этом браузере. Без ключа страница ничего никуда не отправляет.

## Как проверить

Критерии AC-1…AC-28 в `документы/SPEC.md`. Для быстрой проверки сбоя добавьте к адресу `?fail`.
