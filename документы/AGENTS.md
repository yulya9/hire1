# AGENTS.md: как работать с этим кодом

Прототип: один файл `прототип/index.html`, чистые HTML, CSS и JS. Сборки и зависимостей нет. Что должно происходить, написано в `документы/SPEC.md`. Состояния в `STATES.md`, размеры и цвета в `HANDOFF.md`.

## Порядок работы

1. Прочитай `SPEC.md` (разделы 5, 7, 11) и `STATES.md`.
2. Новое поведение сначала допиши в `SPEC.md` (правило, текст, критерий приёмки AC), потом в код. Если код и спецификация расходятся, права спецификация.
3. После правки пройди затронутые критерии AC на странице в Chrome, светлая и тёмная тема, ширина 375 и 1440.

Запуск: `python3 -m http.server 8765` в корне, открыть `http://localhost:8765/прототип/index.html`. Проверка сбоя: добавить `?fail`. Ключ Claude вводит человек сам на `index.html#settings`, ключ в код и в чат не вставляй.

## Как устроен код (искать по именам)

| Что | Где |
|---|---|
| Вопросы, названия разделов, примеры | `TOPICS` |
| Единое состояние | `S` (`phase`: idle, listening, review, building, failed, result; `i`, `answers`, `thin`, `followed`, `hint`, `transcript`, `callErr`, `fix`) |
| Вся отрисовка экрана | `render()` и `renderDoc()` |
| Круг и шар | `animateRing()`, `drawOrb()`, `magUpdate()` |
| Голос | `startListening`, `stopListening`, `onRecEnd`, `isGhost`, `voiceError`, `teardown` |
| Правила ответа | `checkAnswer`, `submitAnswer`, `advance`, `skipQuestion`, `goBack`, `fillGap`, `gaps()` |
| Сборка | `startBuild`, `generate`, `templateResult`, `llmResult`, `clean`, `bulletsOf` |
| Сохранение | `persist`, `resumeInterview`, `clearSaved` (только `sessionStorage`) |

## Правила

- Тексты интерфейса и ошибок берутся из таблицы в `SPEC.md`, раздел 11, дословно. Другой текст сначала внеси в таблицу.
- Цвета только через переменные из `HANDOFF.md`, раздел 3. Хочешь новый цвет: посчитай APCA, добавь токен для обеих тем. Прозрачность в токенах не используем.
- Не добавляй кнопки, экраны и настройки без записи в `SPEC.md`, раздел 14 («Что решили и что убрали»). Вместо новой кнопки поищи способ показать действие в существующем элементе.
- Не добавляй зависимости и сборку. Если нужен модуль, спроси.
- Не отправляй данные пользователя наружу. Единственный разрешённый адрес: `api.anthropic.com`, и только если человек сам ввёл ключ.
- Не стирай ответы без подтверждения: крестик просит второй клик.
- Пустой ответ принять нельзя никогда (SPEC 7.1). Вместо «молча пропустить» показывай подсказку.
- Состояние из таблицы `STATES.md` должно быть достижимо и проверено на странице. Не заводи состояние, которого там нет.
- Уважай `prefers-reduced-motion`: любая новая анимация отключается.

## Чего нет в коде (не ищи)

Серверного распознавания, аналитики, автотестов, сохранения готового документа, входа и списка вакансий. Они в `SPEC.md` в «не входит» или «отложено».

## Проверка перед сдачей

AC-1…AC-28 из `SPEC.md`, раздел 13, в Chrome и Firefox, светлая и тёмная тема. Голос только в Chrome и Edge.
