# Что сделано, что не вошло, как проверить

Версия от 10 ноября 2026. Работающий прототип: <https://yulya9.github.io/hire1/>. Запуск локально: `python3 -m http.server 8765` в корне, открыть `http://localhost:8765/`.

## Что сделано

**Продукт**
- Интервью из четырёх вопросов по одному: старт, вопрос, сборка, документ вакансии.
- Голос и текст в одном поле. Голос: Web Speech API, русский язык, непрерывная запись с живым текстом, таймером и перезапуском, когда Chrome сам обрывает распознавание.
- Круг из 60 засечек: четыре четверти по числу вопросов, шар в центре откликается на голос, магнитный эффект на старте.
- Проверка смысла ответа: пустой не проходит никогда, слишком короткий получает дозапрос с примером, слова-паразиты не считаются ответом.
- Сборка документа вакансии из ответов: «Ищем специалиста.» и четыре раздела. Работает сразу, без нейросети: слова человека чистятся от «ну» и «короче» и раскладываются по разделам. Дополнительно заложена необязательная сборка через нейросеть Claude (нужен свой ключ доступа, включается в скрытых настройках; при сбое возвращается к обычной сборке). В сдаваемой версии она не проверялась на реальном ключе.
- Правка раздела по клику, копирование, «Добавить» для пробелов, «Назад», «Продолжить» после обновления страницы, подтверждение на крестике.
- Тёмная и светлая тема, адаптив от 320 px, уменьшенное движение, клавиатура, статусы для скринридера.

**Документы:** `SPEC.md` (правила, тексты, 28 критериев приёмки), `STATES.md` (11 состояний, пограничные случаи), `HANDOFF.md` (передача в вёрстку), `AGENTS.md`, `PROCESS.md`, `ПРЕЗЕНТАЦИЯ.md`.

**Проверки:** внешнее тестирование делал Grok (отдельные прогоны страницы, списки багов), скриптовые сценарии, замеры и расчёт контраста Claude, живой голос проверял автор (подробнее в `PROCESS.md`). Сценарий пройден на опубликованной странице в текстовом режиме. Голос проверялся подменой распознавания и автором в Chrome. Контраст ключевых пар (текст, подписи, кнопки, активный пункт меню) посчитан по APCA и WCAG и измерен на странице. Десять багов из внешнего тестирования исправлены и прогнаны повторно.

## Что не вошло или не проверено

| Что | Почему |
|---|---|
| Серверное распознавание речи (Whisper) | В Firefox голоса нет, весь сценарий проходится текстом (проверено). В Safari распознавание речи частичное и не проверялось |
| Аналитика событий | Решение не принято, в `SPEC.md` отложено |
| Автотесты экрана | Критерии приёмки проходятся на странице по списку, без автоматического прогона |
| Сборка через Claude с настоящим ключом | Код написан и сбои обработаны, но на живом ключе не пробовала |
| Живой голос в шуме и на разных микрофонах | Проверялся только в Chrome, без замеров в шуме |
| Короткое видео | В задании «прототип или видео»; сдаю прототип |

## Как проверить

1. Открыть <https://yulya9.github.io/hire1/>, нажать «Начать».
2. Нажать «Дальше» на пустом поле дважды: подсказка остаётся оба раза (AC-2).
3. Ответить полно на все четыре вопроса: документ с разделами и меткой «Готова» в шапке (AC-11, AC-12).
4. Пропустить один вопрос: метка «Черновик», «Добавить» у пустого раздела ведёт к нему (AC-13, AC-14).
5. Обновить страницу на втором вопросе: «Продолжить» возвращает с ответами (AC-25).
6. Переключить тему, сузить окно до 375 px (AC-22, AC-24).
7. Добавить `?fail` к адресу и собрать вакансию: ошибка и «Повторить» (AC-21).

Полный список AC-1…AC-28: `SPEC.md`, раздел 13.
