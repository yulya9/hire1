# Состояния и пограничные случаи

Версия 2 от 10 ноября 2026. Дополняет `SPEC.md` (там правила и тексты), здесь матрица: что видит человек в каждом состоянии, как в него попасть и как выйти. Идентификаторы `S1…` используются в критериях приёмки и в коде (`S.phase`, `S.callErr`).

## 1. Матрица экранов

| № | Состояние | Как попасть | Что видно | Выход |
|---|---|---|---|---|
| S1 | Старт | Открыть страницу; крестик (второй клик) | Круг 320 px (магнитный), заголовок, подпись, «Начать» | «Начать» → S3 |
| S2 | Старт с незаконченным интервью | Обновить страницу, пока есть принятый ответ или недописанный текст в поле | Круг с закрашенными четвертями за принятые ответы, подпись «Вы остановились на вопросе N из 4. Ответы сохранены.», кнопка «Продолжить», под ней тихая ссылка «Начать заново» | «Продолжить» открывает вопрос, на котором остановились, с принятыми ответами (S3, если браузер с голосом и режим не текстовый, иначе S4). «Начать заново» стирает ответы и сразу открывает первый вопрос |
| S3 | Вопрос, запись идёт (`listening`) | Открыт вопрос в браузере с голосом; микрофон включён | Круг 280 px, шар и засечки откликаются, таймер, поле с живым текстом, микрофон оранжевый | Микрофон, Escape, печать, тишина 25 с, «Дальше», «Пропустить» |
| S4 | Вопрос, запись остановлена (`review`) | Остановили запись; нет голоса в браузере; печать | Круг и шар неподвижны (оживают от ввода и гаснут), без таймера, микрофон серый | Микрофон снова включает запись, «Дальше», «Пропустить», «Назад» |
| S5 | Подсказка дозапроса | «Дальше» на пустом или коротком ответе | В строке под полем жёлтая подсказка, остаётся до «Дальше» | Новый ответ, «Пропустить» |
| S6 | Ошибка голоса | Нет доступа, нет микрофона, сеть, нет речи 10 с, запись не запустилась, три ошибки подряд | Строка ошибки. Текущая четверть красная при жёсткой ошибке и на третьей ошибке подряд, янтарная при «не слышно», сети и сбое запуска | Печать убирает ошибку. Жёсткая ошибка и три ошибки подряд включают текстовый режим: следующие вопросы сами не слушают, микрофон в поле можно нажать |
| S7 | Сборка (`building`) | Ответ на последний вопрос отправлен | Шар вращается, «Создаём вакансию…», без кнопок; при Claude ссылка «Отмена» | Результат (S9/S10), сбой (S8), «Отмена» → S4 на вопросе 4 |
| S8 | Сбой сборки (`failed`) | Таймаут 60 с, нет сети, 401/403/404/429, непонятный ответ, прочий сбой, `?fail` | Красные засечки, «Не удалось создать вакансию», причина из раздела 11 `SPEC.md`, «Повторить», «Собрать по шаблону» (с ключом), «Изменить ответы» | Повтор снова собирает. «Изменить ответы» открывает вопрос 4 текстом, без автоматической записи |
| S9 | Результат: готов | Все четыре ответа полные | Документ, метка «Готова» в шапке, под текстом «Скопировать» и «Новая вакансия» (с подтверждением, если не скопировано) | Правка раздела, копирование, заново |
| S10 | Результат: черновик | Есть пропуск, «коротко» или очищенный раздел | Документ, метка «Черновик» в шапке, у короткого раздела «коротко», у пустого «Добавить»; под текстом «Скопировать» и «Новая вакансия» | «Добавить» → вопрос с пробелом |
| S11 | Правка раздела | Клик по разделу в результате | Поле с текстом, иконки «Сохранить» (Ctrl/Cmd+Enter) и «Отмена» (Esc) | Сохранить: пустой раздел снова пробел; любой непустой текст снимает «коротко». Отмена возвращает прежний текст |

Фазы кода: S1 и S2 — это `idle`, S3 — `listening`, S4 и S5 — `review`, S6 — `review` с `callErr`, S7 — `building`, S8 — `failed`, S9–S11 — `result`.

«Начать заново» (на S2) и «Новая вакансия» (на результате) стирает ответы и сразу открывает первый вопрос. Крестик со вторым нажатием возвращает на пустой старт (S1). При обновлении страницы восстанавливается всё: в `sessionStorage` лежат принятые ответы, номер текущего вопроса и недописанный текст в поле.

## 2. Переходы с вопроса

| Действие | Условие | Результат |
|---|---|---|
| «Дальше» | ответ полный | Сохраняется, следующий вопрос (или сборка после четвёртого) |
| «Дальше» | пустой (в том числе только слова-паразиты) | S5 «Ответ пустой…», каждый раз |
| «Дальше» | короткий, первый раз | S5 «Можно подробнее?…» |
| «Дальше» | короткий, второй раз | Принят с пометкой «коротко», четверть не закрашена |
| «Пропустить» | всегда, кроме последнего вопроса, когда ни на один нет ответа | Ответ пуст, следующий вопрос; в исключении остаёмся на вопросе, подсказка «Ответьте хотя бы на один вопрос…» |
| «Назад» (вопросы 2–4) | всегда | Текст в поле сохраняется (четверть не закрашивается, если ответ короткий), открывается предыдущий вопрос с его ответом |
| Крестик | нет ответов и поле пусто | Сразу старт |
| Крестик | есть ответы | Янтарный на 3 с; второй клик стирает всё |
| Escape в записи | всегда | Остановка без ошибки |

## 3. Голос: пограничные случаи

| Случай | Поведение |
|---|---|
| Браузер без `SpeechRecognition` | Поле как обычное текстовое, микрофона нет, ошибок нет |
| Отказ в доступе к микрофону | S6 «Нет доступа к микрофону…». Кнопка микрофона остаётся: можно нажать после выдачи доступа |
| Микрофона нет | S6 «Микрофон не найден…» |
| Chrome сам завершил распознавание | Перезапуск, текст сохраняется. Шесть быстрых обрывов (<1,5 с) подряд: остановка, текст остаётся, без сообщения |
| Нет речи 10 секунд после старта | S6 «Не слышно речи…» |
| Нет новых фраз 25 секунд | Остановка записи, текст остаётся |
| Печать во время записи | Запись останавливается, текст остаётся, ошибка (если была) исчезает |
| Системная диктовка macOS | Ввод идёт в поле как обычный; шар и засечки откликаются и гаснут через ~2 с |
| Вкладку скрыли | Запись продолжается 30 секунд, затем останавливается |
| Хвост предыдущего ответа в новой записи | Первые 3 секунды фраза, дословно входящая в прошлый ответ, отбрасывается |
| Диктуют в поле во время подсказки | Подсказка остаётся |

## 4. Сборка и результат: пограничные случаи

| Случай | Поведение |
|---|---|
| Ключа Claude нет | Шаблон, 1–2 с, без «Отмены» |
| Ключ есть | Сборка через Claude до 60 с, ссылка «Отмена» |
| Нейросеть не ответила 60 с | S8 «Нейросеть не ответила за 60 секунд» |
| Ключ не подошёл (401, 403) | S8 «Ключ не подошёл. Проверьте его в настройках нейросети» |
| Модели нет (404) | S8 «Такой модели нет. Проверьте название модели» |
| Лимит (429) | S8 «Лимит запросов исчерпан. Подождите минуту или соберите по шаблону» |
| Нейросеть вернула непонятный ответ | S8 «Нейросеть вернула непонятный ответ» |
| Нет связи с сервисом | S8 «Нет связи с сервисом» |
| Прочий сбой сборки | S8 «Сбой при сборке текста» |
| Один раздел пуст | В документе кнопка «Добавить» вместо текста |
| Все разделы стёрты правкой | Кнопки «Скопировать» нет, остаётся только «Новая вакансия» |
| Копирование запрещено браузером | Документ выделяется, подпись «Не удалось скопировать. Текст выделен, нажмите Ctrl+C» |
| Очень длинный ответ или разметка в тексте | Принимается как текст, вёрстка не ломается |
| Обновление страницы на результате | Старт: готовый документ не сохраняется (ответы уже стёрты при сборке) |

## 5. Что намеренно не делаем

- Автосохранение документа между сессиями.
- Подтверждение при закрытии вкладки.
- Восстановление записи голоса.
- Офлайн-режим: без сети голос не распознаётся (Chrome использует облако), поле остаётся рабочим.
